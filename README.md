# QuickTranslate

基于 Python 与 PyQt5 开发的桌面菜单栏翻译与词典工具。常驻系统状态栏，支持快捷键呼出与平滑下滑动效，唤出即自动聚焦输入框，提供详细词典释义、英美发音、词形变化、短语搭配与双语例句。

## 功能特性

- **菜单栏下拉弹窗**：常驻系统托盘，不占用任务栏与窗口切换列表。按下快捷键或点击托盘图标时从屏幕顶部平滑滑出，失焦或按 ESC 自动收起。
- **自动聚焦与回车查询**：呼出后光标自动对齐输入框，输入后按回车即时查询。
- **专业词典信息**：
  - 英式与美式音标及真人发音
  - 考纲等级（中考、高考、四六级、考研、雅思、托福、GRE）与柯林斯星级
  - 词形变化（复数、过去式、分词等）
  - 常用短语搭配与同义词
  - 词性分组释义与双语例句
- **智能剪贴板识别**：唤出时自动识别剪贴板文本，按 Tab 键可直接填入并翻译。
- **主题自动跟随**：自动检测系统深色/浅色模式并实时切换，亦可在设置中手动指定。
- **历史记录与生词本**：自动保存最近查询历史，支持将生词一键收藏至本地数据库。
- **免 Key 服务与本地缓存**：聚合有道词典与 Google 翻译免费端点，结合 SQLite 本地缓存实现二次查询即时呈现。

## 快捷键说明

| 快捷键 | 功能 |
| :--- | :--- |
| `Ctrl+Alt+T` | 唤出 / 收起面板（可在设置中修改） |
| `Enter` | 触发翻译 |
| `ESC` | 收起面板 |
| `Tab` | 快速填入剪贴板文本并翻译（输入框为空时） |
| `Ctrl + 1` | 播放英式发音 (UK) |
| `Ctrl + 2` | 播放美式发音 (US) |
| `Ctrl + D` | 收藏 / 取消收藏当前词条 |
| `Ctrl + L` | 重新聚焦输入框并全选 |
| `Ctrl + ,` | 打开设置面板 |

## 运行方式

### 直接运行可执行文件

```bash
./dist/QuickTranslate/QuickTranslate
```

桌面快捷方式已自动安装至 `~/.local/share/applications/quicktranslate.desktop`，亦可在系统应用启动器中搜索 `QuickTranslate` 启动。

### 源码运行

```bash
cd QuickTranslate
source venv/bin/activate
python3 run.py
```

## 打包构建

```bash
venv/bin/python3 build.py
```

脚本将调用 PyInstaller 生成二进制文件至 `dist/QuickTranslate/QuickTranslate`，并同步更新桌面启动项。
