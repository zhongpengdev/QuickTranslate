# QuickTranslate (菜单栏极速翻译字典)

专为桌面效率打造的**状态栏/菜单栏极速翻译与词典工具**（Raycast / macOS Menubar Popover 极简风格）。无需前置主应用窗口，常驻顶部菜单栏；按下快捷键或点击菜单栏图标时，窗口**自动从顶部菜单栏顺滑下滑展开**并秒聚光标，收起时自动回缩，干净轻盈。

---

## ✨ 核心特性

1. **菜单栏自动顺滑下滑展开 (Menubar Flyout)**
   - **完全无常驻任务栏窗口**：采用系统托盘 / 状态栏轻量常驻模式，不占用 Alt-Tab 窗口列表与任务栏空间。
   - **平滑下滑动效**：按下快捷键（默认 `Ctrl+Alt+T`，或用户自定义键）或单击菜单栏小图标，窗口从顶部菜单栏以平滑的物理缓动曲线 (`OutCubic`) 优雅下滑展开；失焦、再次按键或按 `ESC` 自动平滑缩回。
   - **光标秒级自动聚焦**：呼出后无需任何鼠标点击，直接敲击键盘输入内容。
2. **主题跟随系统黑白自适应 (Auto System Theme)**
   - 自动智能检测系统级深色/浅色模式（完美适配 GNOME / WhiteSur / KDE / GTK 切换）。
   - 系统黑白模式切换时，界面自动毫秒级同步重绘，同时支持在设置中手动锁定深色或浅色。
3. **极简设计，拒绝粗糙“AI 模板味”**
   - 采用 Linear / Raycast 顶级现代设计语言，无多余大色块与劣质表情符，精致圆角底沿、细腻半透明微边框与呼吸阴影。
4. **内容丰富，专业权威**
   - 🔊 **标准英/美双音标与发音**：原声真人朗读，支持 `Ctrl+1` 播放英音、`Ctrl+2` 播放美音。
   - 📚 **考试考纲与柯林斯星级**：自动标注词汇所属考纲等级（`初中`、`高中`、`CET4`、`CET6`、`考研`、`IELTS`、`TOEFL`、`GRE`）与柯林斯词频星级（`★★★☆☆`）。
   - 🔄 **词形变化**：详细提供单复数、过去式、过去分词、现在分词、第三人称单数等变形拆解。
   - 🔗 **常用短语搭配**：提供高频实用短语与地道中文含义。
   - 💡 **近义词对比**：按词性分组展示常见同反义替换词。
   - 📖 **词性分类详细释义**：按名词 (n.)、动词 (v.)、形容词 (adj.) 等清晰排布。
   - 📝 **地道双语例句**：权威中英文对照例句，自动高亮所查核心词汇。
5. **智能效率拓展功能**
   - 📋 **智能剪贴板识别**：唤出面板时，若剪贴板内有待查文本，自动显示一键填入胶囊，按 `Tab` 键即可一键填入并直接翻译。
   - 🕒 **最近查询历史**：输入框为空时展示最近搜索记录，可一键再次回查。
   - ★ **生词本 / 收藏功能**：点击词条右上角 ☆ 即可快速收藏入库，支持随时从顶部菜单点击 ★ 调出生词本。
   - 🚀 **100% 免费服务**：有道词典开放 Web 端点与 Google Translate 免费服务混合并发，无需任何 API Key，离线 SQLite 零延迟缓存。

## ⌨️ 快捷键速查

| 快捷键 | 功能描述 |
| :--- | :--- |
| **`Ctrl+Alt+T`** | 顶部菜单栏唤出 / 收起面板（可在设置中自定义） |
| **`Enter`** | 在输入框中直接触发翻译 |
| **`ESC`** | 平滑收回窗口至顶部菜单栏 |
| **`Tab`** | 快速粘贴剪贴板待查文本并翻译（输入框为空时） |
| **`Ctrl + 1`** | 播放英式发音 (UK) |
| **`Ctrl + 2`** | 播放美式发音 (US) |
| **`Ctrl + D`** | 快速收藏当前词条至生词本 |
| **`Ctrl + L`** | 聚焦搜索框并全选内容 |
| **`Ctrl + ,`** | 打开偏好设置对话框 |

## 🚀 启动与运行

```bash
# 直接运行打包好的桌面端程序
./dist/QuickTranslate/QuickTranslate

# 或通过 Python 环境运行
cd /home/zhongpeng/Projects/PythonProject/QuickTranslate
venv/bin/python3 run.py
```
*(也可以在系统的应用菜单中搜索 **QuickTranslate** 点击启动)*

## 🛠️ 重新打包构建

```bash
venv/bin/python3 build.py
```
构建脚本将重新生成原生二进制并自动安装桌面启动项至 `~/.local/share/applications/quicktranslate.desktop`。
